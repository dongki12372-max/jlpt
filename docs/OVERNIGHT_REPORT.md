### 2차 결과

**Phase 8 · 단어 데이터**
- 형식: `data/vocab/schema-words.json`, 파일 `data/vocab/words/{n5,n4,n3}.json` (한 줄에 한 단어). 검사 `tools/validate_vocab.py`: key 중복(전 레벨), key=단어|읽기, 가나 단어 표기=읽기, 뜻 최대 3개, 예문 후리가나(지우면 text와 같음·모든 한자), 예문 길이(기준 1.6배 넘으면 경고), 예문에 단어가 있는지(경고), ttsText 읽기 일치, 청해 출처가 실제 청해 vocab과 맞는지, 청해 vocab(word·expression)이 모두 단어 데이터에 있는지.
- 도구: `import_listening_vocab.py`(출처 맞추기·없는 단어 초안), `merge_words.py`(배치 → id 부여 → 합치기, 검사 실패·경고 시 거부).
- 작성: 레벨별 신규 단어 목록을 먼저 만들고(N5 → N4는 N5 제외 → N3는 N5·N4 제외, 읽기 행으로 3분할), 뜻·예문을 배치(110~125단어)로 작성 → 검사 → 합침. 단어 전체를 레벨별 다른 에이전트가 다시 검토해 25곳 수정(예문 부자연·해석 오류·레벨 초과 어휘·후리가나 오류·pos 1).
- 결과: **N5 752 · N4 660 · N3 1,783 = 3,195단어** (word 3,135 + expression 60). 청해 vocab 372개 전부 연결(출처 listening: 372단어).

**Phase 9 · 단어 음성**
- `tools/build_vocab_audio.py`: 단어(N, word를 읽힘 — 동음이의어 구분), 예문(F·M 번갈아), 문항 완성 문장(N). 해시로 바뀐 것만, 3회 재시도, loudnorm, `--prune`.
- `tools/check_vocab_tts.py`: **실제 음성과 가나 읽기로 합성한 음성을 MFCC(0차 제외·정규화)+DTW로 비교**. 시험해 보니 같은 읽기 ≤2.0, 다른 읽기 ≥2.5로 갈림(一日→いちにち, 市場→しじょう 등 실제 오독을 잡음). 기준 2.3 넘으면 의심 → `--fix-*`로 가나 ttsText를 넣고 다시 생성.
  - 의심 → 수정: 단어 N5 51 · N4 30 · N3 65(+ 원래 숫자 등 25), 예문 N5 7 · N4 4 · N3 8, 문항 4. 수정 후 다시 검사해 의심 0.
- 결과: 단어 3,195 + 예문 3,195 + 문항 252 = 6,642개 mp3 (약 170MB). 검사용 가나 캐시(`audio/vocab/_check`)는 빌드에서 제외.

**Phase 10 · SRS 단어장** (`app/renderer/js/vocab/srs.js`, `index.js`, `deck.js`)
- 카드: 단어마다 뜻 카드 + 읽기 카드(가나 단어는 뜻 카드만). 앞면/뒷면·자동 재생·단축키(Space·1~4·R)는 지시서대로.
- 간격: 지시서 12장 그대로, 숫자는 `config.sections.vocab.srs`. 버튼에 다음 간격 미리 보기(1분·10분·4일 …).
- 단어장 홈(오늘 복습·새 카드·범위 선택), 단어 목록(레벨·품사·상태·검색), 단어 상세(카드 상태, 비슷한 말, 나온 청해·문자어휘 문항 → 해설로 이동).
- 확인(smoke): 가짜 시계로 새 카드 → 10분 → 1일 → 3일 → 10일(쉬움) → 어려움 → 다시(1분, 계수 −0.2) → 다시 1일, 계수 하한, 약한 단어, 새벽 4시 경계, 하루 새 카드 한도·다음 날 회복, 읽기 카드는 다음 날부터. 앱을 껐다 켜도 카드 기록 유지(`SMOKE_PERSIST`).

**Phase 11 · 문제 스키마·샘플**
- `data/vocab/schema-questions.json` + 검사: 유형별 문장 모양(밑줄 하나/빈칸 하나/用法은 제시 단어), fullText = 정답을 넣은 문장, **漢字読み 밑줄 한자어에 후리가나 금지·선택지 가나만**, **表記 선택지 한자 포함·후리가나 금지**, 漢字読み 정답 = fullFurigana의 밑줄 읽기, 表記 밑줄 가나 = 정답 표기의 읽기, 선택지 4개 서로 다름, 정답 자리 optionNotes 빈 문자열·오답 자리 필수, targets가 단어 데이터에 있고 레벨 이하, 같은 단어가 같은 유형 targets로 3번 초과 금지, 정답 분포 출력.
- 샘플 28문항 (N5 8 · N4 10 · N3 10).

**Phase 12 · 연습·실전·오답노트·연동** (`vocab/question-view.js`, `practice.js`, `exam.js`)

- **첫 자동 재생 1회 실패 (원인 미확인)**: Phase 5 smoke 첫 실행에서 앱 시작 후 첫 연습 문항 음성이 1.2초 안에 시작되지 않은 일이 1번 있었다(그 뒤 5회 이상 재현 안 됨). 창을 숨긴 상태에서도 새 음성은 정상 시작되는 것을 확인해서 '화면이 꺼져 재생이 미뤄짐' 가설은 아니었다. 오디오 장치 준비 지연으로 추정. smoke는 이제 최대 3초 기다리며 실제 걸린 시간을 기록한다(보통 0.3초, 마지막 실행에서 13번 중 1번 2.2초). 아침에 앱을 켰을 때 첫 문항이 늦게 재생되면 알려 주세요.

## 이어서 하는 방법

이 파일의 진행 상황 표에서 '진행 중'인 단계부터 이어서 하면 된다. 모든 단계는 `.venv/bin/python tools/validate.py`와 `npm run smoke` 통과 후 커밋했다.
