## 남은 문제

- **첫 자동 재생 1회 실패 (원인 미확인)**: Phase 5 smoke 첫 실행에서 앱 시작 후 첫 연습 문항 음성이 1.2초 안에 시작되지 않은 일이 1번 있었다(그 뒤 5회 이상 재현 안 됨). 창을 숨긴 상태에서도 새 음성은 정상 시작되는 것을 확인해서 '화면이 꺼져 재생이 미뤄짐' 가설은 아니었다. 오디오 장치 준비 지연으로 추정. smoke는 이제 최대 3초 기다리며 실제 걸린 시간을 기록한다(보통 0.4초). 아침에 앱을 켰을 때 첫 문항이 늦게 재생되면 알려 주세요.
